# Text

Obviously text is a **very import** part of _Marp_ slides.

This theme is based on the <mark>default</mark> [Marp](https://marpit.marp.app) theme, hence all features of [github-markdown-css](https://github.com/sindresorhus/github-markdown-css) are available.

Like alerts, for example:

<div class="markdown-alert markdown-alert-note">
  <div class="markdown-alert-title">Note</div>

  This theme uses Catppuccin's `red` color as accent.
</div>
